# Robocze specyfikacje i plany funkcji

Notatki z projektowania kolejnych funkcji, pisane przed implementacją, w trzech krokach:
rozpoznanie problemu → specyfikacja z rozważanymi opcjami (`specs/`) → plan wdrożenia (`plans/`).
Nazwa folderu pochodzi od narzędzia, którym prowadzono te sesje.

To jest **archiwum decyzji**, nie dokumentacja bieżąca: część specyfikacji opisuje stan sprzed
późniejszych zmian (np. tracking kontenerów usunięty, linki publiczne dla klienta usunięte).
Aktualny stan: [dokumentacja analityczna 01–07](../README.md). Decyzje wybrane z tych
specyfikacji, z uzasadnieniem: [06-decyzje.md](../06-decyzje.md).

- `specs/` — 38 specyfikacji: problem, decyzje, rozważane i odrzucone opcje, zakres
- `plans/` — 34 plany wdrożenia krok po kroku
